# Similar Roles

FDE sits in the middle of a cluster of customer-facing AI engineering jobs. Industry analyses group applied AI engineer, deployment engineer, field engineer and solutions engineer together when their duties resemble FDE work {{t_titles}}. **If you want to be an FDE, search for all of these titles.**

## FDE family

| Title | How it differs from FDE |
|---|---|
| [**Forward Deployed Engineer**](./forward-deployed-engineer) | The reference role: builds and delivers **after the sale** {{s_after}} |
| **Applied AI Engineer** | Anthropic hires FDEs into its Applied AI team {{pa_anth}} |
| **Implementation / Professional Services Engineer** | Described as the FDE's "closest cousins" {{s_cousins}} |
| **Solutions Engineer** | Pre-sales and often quota-based. FDE owns the post-sale outcome {{p_se}} |
| **Solutions Architect** | "Ships contracts, not code": pre-sales technical fit and proofs of concept {{p_sa}} |
| **Customer Success Engineer / TAM** | Supports rather than builds {{s_cse}} |

## Which one fits?

| If you like… | Aim for… |
|---|---|
| Coding **and** working with people, a fast pace, travel | FDE, Applied AI Engineer |
| Designing and demoing more than building | Solutions Engineer / Architect |
| Pure building, fewer meetings | AI Engineer, Agent Engineer |
| Proving things work, finding failures | AI Evaluation Engineer |
