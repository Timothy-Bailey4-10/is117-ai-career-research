# Sources

## How citations work on this site

On the FDE, Similar roles, Skills, and Find jobs pages, every fact has a small source tag. The tag links to the **exact sentence** on the source page using a [text fragment](https://developer.mozilla.org/en-US/docs/Web/URI/Reference/Fragment/Text_fragments) (`#:~:text=`). In Chrome and Edge the page scrolls to that text and highlights it. Every quoted sentence was checked against the live page on **November 12, 2026**.

Most of these are recruiter or industry blogs with different methods, so the numbers are rough guides. Always check the live job posting.
