## What they do

An **AI agent** is a model that doesn't just answer — it **takes steps**: searching, calling tools, writing files, and checking its own work. Agent Engineers build the "loop" that makes this happen.

```
  ┌──────────┐    decides    ┌──────────┐    result    ┌──────────┐
  │  Model   │ ────────────► │   Tool   │ ───────────► │  Memory  │
  └────▲─────┘               └──────────┘              └────┬─────┘
       └────────────────────── next step ◄──────────────────┘
                     (repeat until done, or hand to a human)
```

## Core work

- **Tool calling** — connect the model to APIs, databases, and apps
- **Orchestration** — split big tasks across sub-agents
- **Memory** — what the agent remembers between steps
- **Guardrails** — when to stop and ask a human
- **Evals** — test pipelines that check the agent behaves

## The senior version: AI Agent Architect

Architects design the overall structure — where tools, sub-agents, and human review fit. It's mostly trade-off and systems-design work, usually for engineers with 8+ years.

## How to break in

- **Backend engineers** reportedly transition in about 2–4 months.
- **New grads** need a strong **public agent project** — something people can try.

**Project idea:** an agent that reads a course syllabus, creates calendar reminders, and asks before changing anything.
