# Similar Roles

FDE sits in the middle of a cluster of customer-facing AI engineering jobs. Industry analyses group applied AI engineer, deployment engineer, field engineer and solutions engineer together when their duties resemble FDE work <sup>[TechScoop](https://techscoop.substack.com/p/why-forward-deployed-engineers-are#:~:text=applied%20AI%20engineer%2C%20deployment%20engineer%2C%20field%20engineer%20and%20solutions%20engineer)</sup>. **If you want to be an FDE, search for all of these titles.**

## FDE family

| Title | How it differs from FDE |
|---|---|
| [**Forward Deployed Engineer**](./forward-deployed-engineer) | The reference role: builds and delivers **after the sale** <sup>[Simpliaxis](https://www.simpliaxis.com/resources/roles-confused-with-fde#:~:text=one%20centred%20on%20building%20and%20delivering%20after%20the%20sale%20is%20genuine%20forward%20deployed%20work)</sup> |
| **Applied AI Engineer** | Anthropic hires FDEs into its Applied AI team <sup>[Paraform](https://www.paraform.com/insights/forward-deployed-ai-engineer#:~:text=Anthropic%20has%20scaled%20its%20Applied%20AI%20team%20aggressively)</sup> |
| **Implementation / Professional Services Engineer** | Described as the FDE's "closest cousins" <sup>[Simpliaxis](https://www.simpliaxis.com/resources/roles-confused-with-fde#:~:text=Implementation%20consultant%20and%20professional%20services%20engineer%3A%20the%20closest%20cousins)</sup> |
| **Solutions Engineer** | Pre-sales and often quota-based. FDE owns the post-sale outcome <sup>[Perspective AI](https://getperspective.ai/blog/forward-deployed-engineer-vs-ml-engineer-vs-solutions-architect-2026/markdown#:~:text=A%20solutions%20engineer%20is%20pre%2Dsales%2Daligned)</sup> |
| **Solutions Architect** | "Ships contracts, not code": pre-sales technical fit and proofs of concept <sup>[Perspective AI](https://getperspective.ai/blog/forward-deployed-engineer-vs-ml-engineer-vs-solutions-architect-2026/markdown#:~:text=Solutions%20architect%20in%20depth%3A%20ships%20contracts%2C%20not%20code)</sup> |
| **Customer Success Engineer / TAM** | Supports rather than builds <sup>[Simpliaxis](https://www.simpliaxis.com/resources/roles-confused-with-fde#:~:text=Customer%20success%20engineer%20and%20technical%20account%20manager%3A%20support%20rather%20than%20build)</sup> |

## Which one fits?

| If you like… | Aim for… |
|---|---|
| Coding **and** working with people, a fast pace, travel | FDE, Applied AI Engineer |
| Designing and demoing more than building | Solutions Engineer / Architect |
| Pure building, fewer meetings | AI Engineer, Agent Engineer |
| Proving things work, finding failures | AI Evaluation Engineer |
