# Similar Roles

FDE sits in the middle of a cluster of customer-facing AI engineering jobs. If you want to be an FDE, **search for and apply to all of the titles below.** Companies often use them for the same work.

## FDE family

| Title | How it differs from FDE | Coding | Customer contact |
|---|---|---|---|
| [**Forward Deployed Engineer**](./forward-deployed-engineer) | The reference role: builds and owns AI in the customer's environment | High | Daily |
| **Applied AI Engineer** | Anthropic's and OpenAI's main label for FDE-style work. Often more architecture and advising | High | Daily |
| **AI Deployment Engineer** | Narrower focus on rollout, integration, and production reliability | High | Often |
| **Solutions Engineer / Architect (AI)** | Mostly pre-sale: designs and demos, then hands off. Sometimes renamed FDE | Medium | Daily |
| **Customer / Field Engineer** | Post-sale technical support and integrations. Can be a stepping stone | Medium | Daily |

## Builder roles (same skills, less customer time)

| Role | Main job | Reported US base* |
|---|---|---|
| [AI Engineer](./ai-engineer) | Build LLM-powered products in-house | ~$160K–$200K |
| [Agent Engineer](./agent-engineer) | Build tool-using AI agents | ~$185K–$320K |
| [AI Evaluation Engineer](./ai-evaluation-engineer) | Measure and test AI quality | Emerging |
| [AI Operations (LLMOps)](./ai-operations) | Keep deployed AI running | ~$155K–$275K |

## Which one fits?

| If you like… | Aim for… |
|---|---|
| Coding **and** working with people, a fast pace, travel | FDE, Applied AI Engineer |
| Designing and demoing more than building | Solutions Architect |
| Pure building, fewer meetings | AI Engineer, Agent Engineer |
| Proving things work, finding failures | AI Evaluation Engineer |
