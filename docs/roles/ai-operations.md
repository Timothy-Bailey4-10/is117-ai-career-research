## What they do

Once an AI system is live, someone has to keep it healthy. AI Operations handles:

- **Model versioning** — which model is running where
- **Prompt deployment** — rolling out prompt changes safely
- **Eval cadence** — re-running quality tests on a schedule
- **Incident response** — what happens when the AI starts misbehaving

## Tools you'll see

Docker, Kubernetes, cloud platforms (AWS, Azure, Google Cloud), monitoring dashboards, and CI/CD pipelines.

## How to break in

- **SREs and DevOps engineers** reportedly move over in about 2–3 months.
- Students: learn **Docker** and **GitHub Actions** — this very site deploys with GitHub Actions, so you can start by reading `.github/workflows/deploy.yml`.
