## What it is

An FDE works directly with a customer to make an AI product work inside that customer's real environment. The defining line: a role built around **building and delivering after the sale** is real FDE work, while one built around demos and supporting the sales process is sales engineering <sup>[Simpliaxis](https://www.simpliaxis.com/resources/roles-confused-with-fde#:~:text=one%20centred%20on%20building%20and%20delivering%20after%20the%20sale%20is%20genuine%20forward%20deployed%20work)</sup>.

The model comes from Palantir <sup>[Fortune](https://fortune.com/2026/09/03/forward-deployed-engineers-fast-growing-six-figure-silicon-valley-job-integrate-ai-with-customers-tech-careers-palantir/#:~:text=Palantir%20has%20long%20been%20known%20for%20its%20forward%2Ddeployed%20model)</sup>. LinkedIn's January 2026 report found FDE roles grew **42×** between 2023 and 2025, compared with 13× for AI engineer roles <sup>[TechScoop](https://techscoop.substack.com/p/why-forward-deployed-engineers-are#:~:text=forward%20deployed%20engineering%20roles%20grew%2042%2Dfold%20between%202023%20and%202025)</sup>.

## What the work involves

- **Discovery and scoping**: OpenAI lists discovery and technical scoping as part of owning a deployment <sup>[Masai School](https://www.masaischool.com/blog/forward-deployed-engineer-skills/#:~:text=discovery%20and%20technical%20scoping)</sup>
- **Integration**: across postings, the common thread is integration work <sup>[Masai School](https://www.masaischool.com/blog/forward-deployed-engineer-skills/#:~:text=The%20common%20thread%20is%20integration%20work)</sup>
- **Production code**: explicitly required in 12 of 14 postings reviewed <sup>[Interview Kickstart](https://interviewkickstart.com/blogs/articles/forward-deployed-engineer-skills-job-posting-analysis#:~:text=the%20most%20common%20requirements%20included%20production%20coding)</sup>
- **Evals and adoption**: OpenAI measures success through production adoption and eval-driven feedback <sup>[Masai School](https://www.masaischool.com/blog/forward-deployed-engineer-skills/#:~:text=production%20adoption%20and%20eval%2Ddriven%20feedback)</sup>
- **Travel**: expect 40–60% travel in many forward deployed AI roles <sup>[Paraform](https://www.paraform.com/insights/forward-deployed-ai-engineer#:~:text=expect%2040%2D60%25%20travel)</sup>

## The interview loop

Paraform's recommended FDE loop <sup>[Paraform](https://www.paraform.com/insights/how-to-hire-a-forward-deployed-engineer#:~:text=Decomposition%20or%20case%20study)</sup>:

| Stage | What it tests |
|---|---|
| Recruiter screen | Motivation and customer-facing communication |
| Practical integration task | Cleaning messy data and wiring up an integration, not algorithm puzzles |
| System design under constraints | Working with legacy databases and incomplete docs |
| Decomposition / case study | Scoping an underspecified problem (the signature FDE stage) |
| Behavioral | Handling stakeholder conflict and ambiguity |

## How to break in

1. Build one AI project for a real user. A strong project includes an **evaluation dataset, defined success criteria, and failure categories** <sup>[Interview Kickstart](https://interviewkickstart.com/blogs/articles/forward-deployed-engineer-skills-job-posting-analysis#:~:text=A%20strong%20project%20could%20include%20an%20evaluation%20dataset)</sup>.
2. Write it up with the problem, architecture, eval results, and what you'd do next. This becomes your story for the case-study round.
3. Apply to the related titles too: Applied AI, Deployment, Field, and Solutions Engineer <sup>[TechScoop](https://techscoop.substack.com/p/why-forward-deployed-engineers-are#:~:text=applied%20AI%20engineer%2C%20deployment%20engineer%2C%20field%20engineer%20and%20solutions%20engineer)</sup>.

::: warning Red flag
Companies use the FDE title for three different jobs <sup>[Bloomberry](https://bloomberry.com/blog/i-analyzed-1000-forward-deployed-engineer-jobs-what-i-learned/#:~:text=three%20different%20jobs)</sup>, and some relabel solutions engineering roles as FDE <sup>[Perspective AI](https://getperspective.ai/blog/forward-deployed-engineer-vs-ml-engineer-vs-solutions-architect-2026/markdown#:~:text=A%20solutions%20engineer%20is%20pre%2Dsales%2Daligned)</sup>. Ask: *"How much of this role is writing production code after the sale, and is any of the pay tied to a quota?"*
:::
