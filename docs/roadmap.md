# Student Roadmap

Most AI postings target people with 2+ years of experience. A student's job is to **build proof** that closes that gap. Here's a four-stage plan.

```text
  Stage 1          Stage 2           Stage 3            Stage 4
 FOUNDATIONS  ──►  FIRST BUILD  ──►  MEASURE IT   ──►   GET SEEN
 Python, Git       RAG app or        Add evals,         Portfolio site,
 SQL, APIs         simple agent      deploy it          internships
```

## Stage 1 — Foundations

1. **Python** — functions, files, APIs, virtual environments.
2. **Git & GitHub** — commit, branch, pull request. *(This repo is practice!)*
3. **SQL** — select, join, group by.
4. **Calling an AI API** — send a prompt, read the response in code.

## Stage 2 — First build

Pick **one** and finish it:

| Project | Teaches | Points toward |
|---|---|---|
| Chat with your class notes (RAG) | Retrieval, embeddings | AI Engineer |
| Assignment-reminder agent | Tool calling, guardrails | Agent Engineer |
| Club or small-business helper | Working with a real user | Forward Deployed Engineer |

## Stage 3 — Measure it

1. Write **20–50 test cases** with expected answers.
2. Score your project automatically.
3. Change one thing, re-score, and record the difference.

This is the step most student projects skip — and the one interviewers ask about most.

## Stage 4 — Get seen

1. Publish a write-up for each project (a page on a site like this one).
2. Apply for **software engineering internships** on teams that use AI.
3. Look for **AI Trainer** or evaluation contract work in a subject you know well.
4. Ask every interviewer: *"How is this role measured?"*

## Checklist

- [ ] Python fundamentals
- [ ] Comfortable with Git and GitHub
- [ ] One finished AI project, deployed
- [ ] Evaluation results for that project
- [ ] Public write-up
- [ ] Applied to 10+ internships
